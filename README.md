# 🩺 Diabetes Prediction
Diabetes is a chronic health condition that affects how the body processes blood sugar (glucose). Early prediction of diabetes can help in timely treatment and lifestyle changes.  
This project uses **Machine Learning** to predict whether a person is diabetic or not based on various medical parameters.  

## 🚀 Project Objective  
The objective of this project is to develop a **Diabetes Prediction Model** using the **Random Forest Algorithm** that provides accurate results by analyzing patient data.  

## 🧠 Machine Learning Model  
**Algorithm Used:** Random Forest Classifier  
- Handles large datasets efficiently.  
- Reduces overfitting using multiple decision trees.  
- Provides better accuracy compared to single-tree models.  

## 🧾 Dataset  
- **File:** `Diabetes Prediction Dataset(in).csv`  
- **Source:** Public dataset (e.g., Kaggle or UCI Repository)  
- **Features include:**  
  - Glucose Level  
  - Blood Pressure  
  - BMI  
  - Insulin  
  - Age  
  - Outcome (1 = Diabetic, 0 = Non-Diabetic)  

## 🧩 Steps Involved  
1. **Load Dataset** – Import data using Pandas.  
2. **Data Preprocessing** – Handle missing values, encode labels, and scale the data.  
3. **Split Dataset** – Divide data into training and testing sets.  
4. **Model Training** – Train the Random Forest model.  
5. **Model Evaluation** – Check accuracy, generate confusion matrix and classification report.  
6. **Visualization** – Display heatmap for confusion matrix and accuracy results.
